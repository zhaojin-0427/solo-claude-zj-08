# 管风琴机械传动放样台（Organ Action Layout Bench）

在狭窄琴柜内，为机械键盘到风箱阀板的传动重新放样。本机运行的
**Python Flask + SQLite** 后端负责物理计算、布局搜索与持久化；浏览器用
**原生 HTML/CSS/JavaScript + SVG** 绘制键盘、滚轴板、转角器、连杆与阀板。

## 运行

```bash
python3 -m venv .venv
.venv/bin/python /tmp/get-pip.py          # 若系统没有 pip
.venv/bin/pip install flask
.venv/bin/python -m organlab.app          # http://127.0.0.1:5000
```

数据库文件 `organlab/organlab.db`（SQLite）首次启动自动创建。

## 功能

* **俯视放样台（SVG 可交互）**
  * 拖动方块支点：键杠支点（立木孔距联动）、立木侧向位置、滚轴板（整板
    前后移动，受“锁定”约束）、转角器位置；
  * 点击臂上小圆孔在档位间切换：键杠立木孔、滚轴输入/输出角孔；
  * 点击连杆端部节点连接 / 断开构件；
  * 侧视页沿选中键的进深方向画整条传动链，按键播放时逐级运动。
* **逐级物理计算**：各级臂长、初始夹角、滚轴角安装仰角、连杆刚度、
  回位弹簧力、风压、铰点效率 → 键程、阀板开启量、触键力、空程、
  各杆弹性变形、压力角。播放时逐级查看位移与受力。
* **违规检查（在图上标出）**
  * `DEADPOINT` 死点（滚轴角安装角过大，行程中转到 90° 竖直顶死）；
  * `COLLIDE` 构件碰撞（实体净距 < 8mm）；
  * `CROSS` 交叉连杆擦碰（标出交点）；
  * `SLANT` 侧向偏折（俯视偏移 / 杆长 > 6%）；
  * `TRAVEL` 阀板行程不足；`FORCE` 触键力超限；`BOUNDS` 越出柜体。
* **锁定与布局搜索**
  * 可锁定单个音键与柜内固定件（滚轴板 / 风箱 / 键盘框架），
    锁定对象不参与搜索与拖拽；
  * 在孔位、臂长、安装角、阀列偏移与滚轴板进深范围内搜索
    （邻居枚举 + 确定性贪心修复 + 受限随机采样）；
  * 结果按 **违规数 → 最大触键力 → 键间手感差 → 改孔量** 排序，
    一键“采纳”后几何与计算参数写回并入库；
  * 快照保存 / 恢复方案。
* **装配图**：生成带 D1…Dn 编号尺寸引线、编号尺寸表与计算参数表的
  **正视 / 侧视装配图（SVG，可下载）**。

## 物理模型要点

```
键前端下压 → 键杠绕轴 → 立木竖直上推
          → 滚轴输入角（安装角 β，转动 ψ）→ 输出角
          → 上行木连杆（压杆，弹性缩短）
          → 转角器折角杆（输入臂 θ=45°，与输出臂初始夹角 α，转动 φ）
          → 阀拉索（拉杆，弹性伸长）→ 阀板（风压+回位簧预紧，开启后弹簧加力）
```

* 滚轴：`升程 = hin·(sin(β+ψ)−sinβ)`，`β+ψ→90°` 为竖直死点，
  触键力按压力角 `1/cos` 放大并封顶标注；
* 转角器：输入/输出臂位移用正弦差，力矩平衡经压力角与铰点效率
  反推（`η=0.93/铰点`）；
* 弹性相容：阀板端位移与连杆压缩通过二分转角 φ 求解
  `d_out = δin(φ) + Fa(φ)/Ka`；
* 阀板响应：拉索先消纳风压/簧/自重预紧（贡献空程），再开启。

种子工程（8 键）故意埋入缺陷供演示：K2 输入角安装 68°（死点、力顶满）、
K3↔K4 交换阀列（上行连杆交叉擦碰 + 偏折）、K5 输出臂最短（行程不足）。
搜索第一名可恢复为零违规布局（改孔量约 8，最大力 ≈ 8N，手感差 ≈ 0.5N）。
